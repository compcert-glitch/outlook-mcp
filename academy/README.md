# Crawford & CO Surveyors Academy — Behaviours & Emotional Intelligence

**The Doorstep Standard** — `doorstep-standard.html`

A six-month behavioural curriculum for field surveyors, written for an RICS
chartered practice specialising in energy efficiency, retrofit and building
pathology. It trains the gap between a correct diagnosis and a client who acts
on it.

## Contents of the pack

| Section | What it is |
| --- | --- |
| 01 Why behaviour is technical | The business and risk case, mapped to the RICS Rules of Conduct |
| 02 The six behaviours | Framework with descriptors at Foundation / Practising / Leading |
| 03 Emotional condition ratings | ECR 1–3 triage, borrowing the condition-rating grammar surveyors already use |
| 04 The six modules | One half-day a month, 18 hours formal CPD, with APC competency mapping |
| 05 Field tools | First Ninety Seconds, LEVEL, Hold the Finding / Move the Person, Two-Minute Debrief |
| 06 Scenario library | Ten role-play scenarios, each rated ECR 1–3 |
| 07 Embedding it | Case clinics, ride-alongs, peer pairs, 1:1 questions, printable observation card |
| 08 What we measure | Nine measures with sources and cadence; baselines deliberately blank |
| 09 Rollout | Nine-month plan, seven cohorts, and what it needs from the business |

## Notes

- The file is a self-contained HTML page (fonts from Google Fonts; no other
  external dependencies). It is print-styled — the observation card in section 07
  is designed to be printed for ride-alongs.
- Baseline figures are intentionally left blank. They come from the practice's
  own complaints log, QA, scheduling and HR data.
- Regulatory references (Rules of Conduct, APC mandatory competencies, CPD hours,
  damp and mould duties in social housing) are included as mapping and should be
  verified against current published requirements before the pack is issued.
- Starter scenarios should be replaced with anonymised real cases from the firm's
  own files as the library matures.

## Why this sits in this repository

This is content authored in a session on this repo, kept under version control
so the Academy pack has a change history. It has no relationship to the
outlook-mcp server code and is not loaded by it.
